### About

Hi, I'm **determine**, an M.S. student at Shanghai Jiao Tong University with a B.Eng. in Artificial Intelligence from Chengdu University of Technology. I build practical AI agent systems and explore the infrastructure that makes them reliable and efficient.

I use this space to document projects, reproducible experiments, paper implementations, and lessons learned while building software.

I'm open to AI Agent and AI Infra internship opportunities in the Yangtze River Delta.

### Focus

| Area | What I'm exploring |
| --- | --- |
| **AI Agents** | Tool use, RAG, memory, workflow orchestration, and evaluation |
| **AI Infrastructure** | Triton kernels, inference efficiency, and cross-backend experiments |
| **Embodied AI** | Robotics, simulation, and control |

### Selected projects

- [**react-agent**](https://github.com/determine123/react-agent) — a multi-tool ReAct agent project exploring retrieval, memory, and workflow orchestration.
- [**flagos-s2-track1**](https://github.com/determine123/flagos-s2-track1) — team work on Triton kernel optimization and cross-backend performance experiments. See the [experiment notes](https://github.com/determine123/flagos-s2-track1/blob/main/docs/EXPERIMENTS.md).
- [**rd-efficiency-daily-assistant**](https://github.com/determine123/rd-efficiency-daily-assistant) — a source-aware assistant for assembling structured engineering updates.
- [**hupiao-treehole-app**](https://github.com/determine123/hupiao-treehole-app) — an Android beta and Python backend for an anonymous community for people living in Shanghai.
- [**Personal blog**](https://determine123.github.io/determine/) — technical notes, project journals, and travel stories.
